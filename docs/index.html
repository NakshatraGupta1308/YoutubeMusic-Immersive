Install in a minute

Get it running

The extension is not on the Chrome Web Store, so you load it once as an unpacked extension. It works in Chrome and Edge.

  1. Download and unzipGrab the zip, then extract it to a folder you will keep, such as Documents. Chrome reads it from there each launch.
  2. Open the extensions pageGo to chrome://extensions (or edge://extensions) and switch on Developer mode.
  3. Load unpackedClick Load unpacked and choose the extracted folder, the one that contains manifest.json.
  4. Play a songOpen music.youtube.com, start a track, then click the bars icon in the player bar or press Alt + V.

FAQ

Why is it not a one-click install?

One-click installs need a listing on the Chrome Web Store. Until then, Chrome's Load unpacked option installs the extension straight from the folder, and it stays installed between launches.

Does it send my listening data anywhere?

No. Audio analysis happens locally in your browser. The only network request is a lyrics lookup to lrclib.net that includes the track title, artist, album and length.

Why do some songs have no synced lyrics?

Lyrics come from the LRCLIB database. Some tracks only have plain text, which scrolls with the song, and a few have none. The other lyric styles need synced lyrics and fall back to Scroll when a track only has plain text.

The visuals look stuck or silent after an update.

Refresh the YouTube Music tab once. Chrome only lets a page's audio be hooked one time, so a reloaded extension needs a fresh page.

Is it affiliated with YouTube?

No. This is an unofficial, open source project and is not affiliated with YouTube or Google.
